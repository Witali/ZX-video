# TRD duplicate consolidation

2026-10-12. Baseline `ead95787f25dfc9a2e18abf46f313f5e73de4143`.

**283 full images -> 189 full images.** Remove 65 exact copies and store 29 almost identical archived variants as sparse edits: **94 removed TRDs / 61,603,840 logical bytes (58.75 MiB)**. The sparse edits contain 8,536 changed bytes, including repeated aliases. JSON, guides and the small restoration helper add their own metadata overhead. These are file-byte counts, not a measured filesystem free-space delta.

The public YouTube-linked `ZX-audiobook-IMA-ADPCM-direct-test.trd`, accepted IMA3 speech reference and complete release sets retain their original bytes. `ZX-audiobook-max-IMA4.trd` is the retained exact copy of both former `ZX-audiobook-IMA4-PDM-search-test.trd` and `ZX-audiobook-quality-IMA4.trd`.

## Comparison and decisions

Compare all materialized 655360-byte images by SHA-256, then compare all pairs of the 218 unique images by byte position. Inspect the TR-DOS directory to locate changed files; never use a high equality percentage caused by empty disk sectors as proof of equal audio. There were 76 nonidentical pairs within 2048 changed bytes.

Retain root release names first, then selected fixtures. Near-duplicate removal is restricted to archived phase-calibration or pre-loading-label variants: the complete directory, data, tables and unused bytes match, and only PLAYER bytes differ. Preserve every differing byte as an offset/hex edit against one retained image; authenticate both SHA-256 identities. Thus a different loop phase is not silently replaced with a different-sounding timing model. Each restored variant is byte-identical to its own original.

Examples deliberately retained despite small differences:

- AY tracked50 versus noise-colour: 716 changed bytes are in AUDIO0/AUDIO1, changing sound.
- Generic CB41 versus 10-fps fixtures: even 14 changed bytes include a different playback cadence.
- Single-volume versus all-volume IMA3: loader/continuation behavior differs despite the same first audio part.
- Final refined movie disk 4 versus the side-seek experiment: preserve the independently verified whole-set identity and the distinct experiment.
- Weighted versus phase-locked PDM and different LZSA2 implementations: small code changes remain meaningful independent experiments.

## Verification and reuse

[Reviewed manifest with exact byte edits](2026-10-12-trd-deduplication.json). [Complete pair comparison](2026-10-12-trd-comparison.json). [Current disk catalogue](../../TRD_CATALOG.md).

Before deletion, reconstruct all 94 candidates and compare every byte to their materialized originals. After deletion, authenticate all retained images and reconstruct every removed SHA-256 again. No player, audio encoding, timing constant or retained disk byte changes. Fresh playback is unnecessary for byte-identical retained artifacts; this cleanup makes no new sound-quality claim.

Four archive-integrity tests pass. The accepted IMA3 music image rebuilds byte for byte; an initial test attempt hit a sandbox Temp-directory access error, and the same test passes with a task-local temporary directory. Both full IMA4 `--build-only` reproductions pass complete saved-artifact authentication and produce the original hashes: ordinary `a7e4fb4f289b036b2f84e2032938894767875db3b1e70fbe19d79780af106aa7`, normalized `e734494907b00ba0e5bbb36b65f37152710fd73ac06efc0865f728a0037b8004`. These are build/identity checks, not fresh Fuse playback runs.

Historical measurement JSON and producer snapshots continue to describe their original files. Markdown links for exact aliases point to the retained copy; links to timing variants point to immutable history. The two full IMA4 reproduction wrappers authenticate deduplicated artifacts through `trd_duplicates.read_bytes`; their saved input streams still rebuild the same full disk. Other old standalone archive scripts may require restoring their original TRD paths before a whole-bundle check. Git/LFS history and remote objects were not rewritten or pruned.

Run the read-only checks:

```powershell
python toolkit/catalog_trd.py --check
python toolkit/trd_duplicates.py --check
```

Restore one archived image to a separate output without downloading history or changing the retained image:

```powershell
python toolkit/trd_duplicates.py --restore "audiobook-beeper/experiments/ima-waveform/calibration/phase-01/audiobook-preview.trd" --output ".tmp/restored-phase-01.trd"
```

The output must not already exist. For a legacy script that requires the original relative path, explicitly pass that same old path as `--output`. This creates an untracked working copy, not a new tracked release.
