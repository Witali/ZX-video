# Сравнение синтеза с измеренным временем Fuse

17 сентября 2026. `compare_ay_trace.py` проверяет все записи регистров
через `verify_ay_trace.py`, затем размещает состояния AY по отметкам
завершения обработчика. Используется частота AY 1773450 Гц — половина
тактовой частоты модели Spectrum 128 в Fuse.

Это приближённый синтез по измеренной трассе, **не запись звукового выхода**.
Записи одного прерывания считаются одновременными; модель сохраняет фазу
тонов и шума, но не воспроизводит точные счётчики AY и аналоговую схему.

| Метрика | Равномерные 50 Гц | По времени Fuse |
|---|---:|---:|
| Спектр по полутонам | 0,86017 | 0,85403 |
| Chroma | 0,95652 | 0,95269 |
| Динамика | 0,99324 | 0,98598 |
| F1 атак | 0,75601 | 0,75601 |

Первый том звучит 118,38971 с вместо номинальных 118,44 с, второй —
1,55918 с вместо 1,56 с. Это следствие фактической частоты IRQ; исправлять
дрейф растяжением WAV при сравнении нельзя. Каждый том сравнивается со
своим участком оригинала; до его номинального конца добавлена тишина
(50,295 и 0,816 мс). Непрерывное воспроизведение с одной дискеты ещё не
подтверждено. Сводка: `ay_timed_measurements.json`.

Новые обязательные технические пороги chroma/динамики 0,95 сохраняются
и при этом более строгом сравнении. Это не подтверждает 95% сходства на слух.

```powershell
python toolkit/compare_ay_trace.py toolkit/build_audio_irq_trd --timing toolkit/build_audio_irq_trd/fuse_timing.json --ay-50hz toolkit/build_audio_rate_experiment/50Hz/raw.bin --rate-report toolkit/ay_rate_measurements.json --input-video SOURCE.mov --ffmpeg ffmpeg --output toolkit/build_audio_irq_comparison
```

Скрипт сохраняет полный WAV и два фрагмента 60..84 с одинаковой RMS-громкости
для прослушивания. Оригинал проверяется по прежнему PCM SHA-256.
