# Постоянные строки атрибутов: инициализация вместо повторного копирования

19 сентября 2026, база `469402c`, FAP3 zero-copy/no-op. Полный профиль
4221 кадров без титров установил: атрибуты **0..95 и 672..767** всегда
равны **1**. Это верхние и нижние три строки по 32 ячейки. Растровые
данные и атрибуты средней части не меняются.

## Изменение

При `--constant-attribute-borders` cold-init после очистки экранов
заполняет все 768 атрибутов каждой экранной страницы единицами.
Перед первой публикацией renderer переписывает 576 атрибутов середины;
неизменные края уже готовы. Компактный кадр и декодер атрибутов остаются
прежними: особенно важно не менять нулевую базу для дельты первого кадра.

Для другого фильма применять опцию можно только после проверки всех
кадров. Benchmark явно отклоняет вход, если хотя бы один атрибут в
пропускаемых строках отличается от 1. По умолчанию код копирует все
768 атрибутов, как прежде.

## Такты, память, диск

По [таблице Zilog](https://www.zilog.com/docs/z80/um0080.pdf) группа из
16 `LDI` плюс `DEC A; JP NZ` занимает **270 T**. Число групп сокращено
с 48 до 36. Настройка адресов имеет прежнюю стоимость 58 T.

| Участок | До, T | После, T | Разница |
|---|---:|---:|---:|
| Цикл копирования атрибутов | 12960 | 9720 | −3240/кадр |
| Стадия атрибутов с настройкой | 13018 | 9778 | −3240/кадр |
| Полный cold-init | 397967 | 430251 | +32284 один раз |

За 4221 кадр формула даёт **−13676040 T** основной работы. Это проекция
по постоянной разнице, а не отдельный полный прогон ускоренного фильма.
В неё не включены ULA, IRQ, ROM и физический диск.

Горячий код не растёт: меняются три непосредственных операнда (начало,
длина, число групп). Инициализатор получает две операции заполнения через
LDIR — **+26 байт**, помещается ниже `7B70`, начала стека ZX0. Новых
буферов или переменных нет. FAP3/ZX0 и число секторов данных прежние;
расход окончательного загрузчика должен проверяться при сборке TRD.

## Проверки и команды

Короткий интеграционный тест исполняет настоящий cold-init и проверяет
оба экрана, compact frame, AY и точную разницу −3240 T на четырёх кадрах,
со stored/ZX0 блоками по 509 байт и кольцом с `FFFF`. Отдельный тест
внедряет настоящий ISR после каждой инструкции копирования атрибутов;
проверяются регистры, AY, стек и итоговые экраны.

```powershell
python toolkit/profile_constant_attributes.py --states .tmp/no_credits/source/conversion.npz --output toolkit/constant_attributes_profile.json
python -m unittest toolkit/test_constant_attribute_borders.py toolkit/test_frame_output_pipeline.py toolkit/test_bulk_frame_z80.py
python toolkit/benchmark_frame_stream.py --raw .tmp/lean_frame/stream.raw --states .tmp/no_credits/source/conversion.npz --storage-report toolkit/lean_frame_zx0.json --cache .tmp/lean_frame/zx0/optimal --baseline toolkit/selective_cache_pipeline_cpu.json --output toolkit/constant_attribute_clock_cpu.json --zero-copy --skip-noop-runs --constant-attribute-borders --cadence --lookahead
python toolkit/summarize_constant_attributes.py --profile toolkit/constant_attributes_profile.json --baseline toolkit/lean_frame_cpu.json --clock toolkit/constant_attribute_clock_cpu.json --cells .tmp/raw_attributes_128/cells.raw --output toolkit/constant_attribute_summary.json
```

Отчёты: [полный профиль](constant_attributes_profile.json),
[частичный прогон с таймером](constant_attribute_clock_cpu.json).
Этот эксперимент не меняет корневые TRD и сам по себе не подтверждает
точное расписание всего фильма или доставку с настоящей дискеты.

## Результат проверки расписания

10 тестов общего тракта/пакетов прошли, отдельно прошёл новый тест ISR.
Таймер с настоящими прерываниями 70908 T, идеальным producer и без ULA
проверил 405 кадров: **44 опоздания вместо 49**, первое на кадре **62
вместо 61**. Максимальная фаза — **284794 T** вместо 316677 T.
Сбой AY остался на кадре 405/tick 2430. Номинальные сроки и резервный
допуск не соблюдены; это частичный прогон, не готовый выпуск.

Решение: сохранить проверяемую опцию ради сокращения постоянной работы.
Полный детерминированный прогон FAP3 без этой опции ещё выполняется;
итоговый бюджет с опцией будет явно помечен проекцией по −3240 T/кадр.
[Аудит сроков](constant_attribute_timing.json) хранит также восстановление
после задержек и измерения по T-states, а не только по счётчику полей.
