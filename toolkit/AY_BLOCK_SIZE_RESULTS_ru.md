# Блоки 6 КБ: стабильное видео с AY 50 Гц

На прежнем контрольном фрагменте 120 с сохраняются все 1000 экранов и
6000 состояний AY. Меняется только офлайновое разбиение на блоки; бинарный
PLAYER одинаковый, 5120 байт. Дельта стоимости каждой инструкции/процедуры
Z80 — 0 T. Прежние абсолютные формулы сохранены в build_metadata.json.

| Лимит блока | Всего секторов VIDEO | Максимум кадра, мс | Интервалов >125 мс |
|---|---:|---:|---:|
| 8192 | 2594 | 128,549156 | 3 |
| 6144 | 2623 | 124,641236 | 0 |
| 4096 | см. JSON | 124,962925 | 0 |

Выбран лимит 6144: результат включает распаковку, запись экрана, paging,
IRQ и модель диска Fuse. Дополнительные 29 секторов не ухудшили темп.
Два тома содержат 979 + 21 кадр; пауза смены диска не входит в интервалы.

Детерминированная подготовка CPU, T на кадр (без IRQ, ULA, ROM и диска):

| Работа | 8192 | 6144 | Разность |
|---|---:|---:|---:|
| Передний план, среднее | 133609,3978 | 130891,7084 | −2717,6894 |
| Фон, среднее | 84476,5120 | 83967,7184 | −508,7936 |
| Сумма, среднее | 218085,9098 | 214859,4269 | −3226,4829 |
| Передний план, максимум | 436195 | 420178 | −16017 |

Разница связана с данными ZX0 и распределением работы, а не ускорением
самого декодера. ROM измеряется отдельно: среднее обслуживание первой
дискеты 7,9525 мс; максимум 193,4419 мс включает запуск привода. Это модель
Fuse 1.9.0 / Spectrum 128 / Beta128 / TR-DOS 5.03, не физический привод.

CPU-валидатор подтвердил 1000 экранов, оба экранных банка и 6000 тактов.
Трасса Fuse подтвердила 10940 записей AY; 1451 неизменившийся такт не делает
I/O. Интервалы обработки звука 19,7375..20,1959 мс, недогрузок нет.
Приближённый синтез по этим отметкам: chroma 0,95267, динамика 0,98595,
полутоновый спектр 0,85396, F1 атак 0,75694. Это не 95% сходства на слух.
103 теста пройдены. Хеши и подробности: `ay_block_size_measurements.json`,
`ay_6144_fidelity_measurements.json`.

Для повторения добавить `--block-bytes 6144` к командам сборки из
`AY_INTERRUPT_RESULTS_ru.md`; измерение и CPU-проверку запускать для нового
каталога. Сводка трёх сборок:

```text
python toolkit/summarize_ay_blocks.py toolkit/build_audio_irq_trd toolkit/build_audio_irq_6144 toolkit/build_audio_irq_4096 --output toolkit/ay_block_size_measurements.json
```

Следующий этап по просьбе пользователя — весь исходный мультфильм без
120-секундного ограничения. Эти измерения относятся только к контрольному
фрагменту; полный фильм требует новой проверки.
