# Передача длины неизменённых серий: скорость и цена в байтах

19 сентября 2026, база `2f8535e`. Все 4221 кадр без титров, FAP3,
неизменные compact-состояния и 25326 записей AY. Цель — сократить
служебную работу без новых изменений изображения. Это проверенные
экспериментальные пути; **трёхдискетный выпуск не получен**.

## Измеренная причина и два формата

[Профиль полного CPU](lean_frame_profile.json), построенный
[сохранённым скриптом](profile_player_cpu.py), даёт 95142825 T в сканере
пустых серий. Он повторно читает векторы и маски, чтобы обнаружить конец
серии. Новый encoder сообщает длину заранее: код 129..144 пропускает
1..16 плиток с вектором 0 и нулевой маской, не пересекая полосу из 16.

- **FAP4** собирает команды подряд и дополняет поле векторов нулями до
  прежних 192 байт. Это 435521 команда вместо 810432 плиток за фильм.
- **FAP5** сохраняет позиции всех векторов, заменяя нулевой первый
  вектор выбранной серии её длиной. Проверены пороги 1, 4 и 16 плиток.
- Длины пакетов, маски, cache/native карты, Huffman, литералы и AY
  сохраняются. Все четыре потока независимо восстановлены в исходный
  FAP3 побайтно. Новых изменений пикселей нет, raw-размер прежний 3097959.

## Полный optimal ZX0, 379 блоков по 8192

Все блоки каждого варианта распакованы независимым PC-декодером.
Четырёхбайтовые заголовки включены, загрузчики/границы томов не включены.

| Вариант | Байты | Разница с FAP3 | Добавленные секторы |
| --- | ---: | ---: | ---: |
| FAP3 | 1932429 | 0 | 0 |
| FAP4, все серии | 2028827 | +96398 | +377 |
| FAP5, от 1 | 2039563 | +107134 | +419 |
| FAP5, от 4 | 1979717 | +47288 | +185 |
| FAP5, только 16 | 1937561 | +5132 | +20 |

Даже сокращение числа команд не улучшает итоговый ZX0. У последнего
варианта осталось всего 103 байта от предварительного бюджета 1937664;
это **не доказательство размещения** трёх самостоятельных дискет.

## Z80, абсолютные такты и память

Изменения генерируются опцией `encoded_noop_runs`: True для FAP4,
`inplace` для FAP5. Старые варианты выключенной опции сохранены.
Короткие неупакованные серии можно обрабатывать прежним сканером через
`skip_noop_runs`. Все формулы сверяются с выполнением инструкций Z80.
Учитывается путь от `tile` до следующего `tile`/`stripe_done`, без IRQ,
ULA, ROM и диска. k — длина серии.

| Путь | Абсолютное время | Разница с прежним сканером |
| --- | ---: | ---: |
| Старый сканер, конец полосы | 92k+200 | 0 |
| Старый сканер, затем ненулевой вектор | 92k+236 | 0 |
| Старый сканер, затем нулевой вектор с коррекцией | 92k+282 | 0 |
| FAP4 без сканера, конец/продолжение | 230 / 240 | 230 или 240 минус соответствующая строка выше |
| FAP5 без сканера, конец/продолжение | 242 / 252 | то же с 242 / 252 |
| FAP5 со сканером коротких серий | 256 / 266 | то же с 256 / 266 |

Полная пустая полоса: **1672 → 256 T, −1416** в смешанном FAP5.
Его обычные ненулевые векторы получают **+17 T** (CP 128 и JP NC),
нулевые векторы и короткие серии обрабатываются прежним сканером.
Без сканера все обычные плитки получают +17 T к исходному обходу
до внедрения сканера; полный расчёт учитывает эту другую базу.

FAP5 со сканером: основной код 3997 → 4002 байта; вспомогательный
88 → 132, **всего +49 байт**, состояние прежнее. Сканер 7A00..7A57,
обработчик 7A80..7AAB, до cold-init 7B00 остаётся место. Конец основного
кода 8FA2, до renderer 9000. Два экрана, AY, стеки, словари, история ZX0
и 64-КиБ кольцо диска прежние. Новых переключений банков не добавлено.

Полная покадровая **проекция реконструкции**, не полного проигрывателя:

| Выбор | Реконструкция, T | Разница с 700958467 T |
| --- | ---: | ---: |
| FAP4, все серии, без сканера | 657087709 | −43870758 |
| FAP5, от 1, без сканера | 658449661 | −42508806 |
| FAP5, от 4, со сканером | 670275257 | −30683210 |
| FAP5, от 16, без сканера | 720944218 | **+19985751** |
| FAP5, от 16, со сканером | 688393023 | −12565444 |

Без сканера коротких серий последний вариант замедляет 3495 кадров;
отклонён. Смешанный вариант замедляет только один кадр. Ввод/ZX0 нельзя
проецировать по этой таблице: сжатые байты и работа decoder изменились.

## Реальный таймер: частичный отрицательный результат

FAP5/16 со сканером, zero-copy, чёрные поля, опережающий ZX0, настоящий
ISR каждые 70908 T. **406 публикаций** и соответствующие compact/native,
курсорные и AY данные проверены в общей памяти. Строгое равенство
покадровой разницы реконструкции формуле также проверено.

- На этом же префиксе foreground **−1211972 T**: реконструкция −1292497,
  ZX0 +72103, reader −42, scheduler +8464; остальные стадии прежние.
  Объём предварительно распакованной будущей работы может различаться.
- Опозданий **43 → 39**, первое по-прежнему 62. Максимальная фаза
  **359193 → 344012 T**. Возврат к сроку первой серии — на 87 вместо 88.
- Сбой остаётся на кадре **406 / AY tick 2436**. Номинальные сроки и
  резервный допуск не соблюдены. Это идеальный producer, без ULA/ROM/диска.

Пять тестов прошли: все длины серий 1..16, границы и следующие коррекции,
motion/intra/fast-плитки, оба экрана и индикатор, raw/coded атрибуты,
ZX0-переходы страниц, AY и точные инструкции. Настоящий ISR проверен
на границах инструкций обоих обработчиков и смешанного пути. Регрессия
прежнего сканера пройдена. Первоначальный счётчик команд FAP5 считал
занятые позиции; исправлен на число исполняемых команд, двоичные потоки
и их хеши не изменились.

## Решение и следующий шаг

Не заменять FAP3 этими потоками в выпуске: дополнительный размер не
решает дефицит CPU и почти исчерпывает место. Опции и отчёты сохраняются
для воспроизведения, корневые TRD прежние. Прежний маленький поток остаётся
рабочей базой. Следующий проверяемый путь — специальный пропуск крайних
компактных полос с сохранением исключений, без новых тегов в данных.
Аудит показывает только 16 fill-векторов 88 в каждой крайней полосе,
все на кадре **4086** (склейка после удаления титров), и ни одной маски
коррекций за весь фильм. Предварительное предположение о первом кадре
опровергнуто проверкой индексов. Нельзя пропустить команды заполнения
4086 или изменить прохождение потока литералов; остальные кадры имеют
нулевые векторы и маски в обеих полосах.

python -m unittest toolkit/test_vector_runs.py test_noop_runs_z80.NoopRunTests.test_motion_intra_fragments_and_cache_preserved
