# Заметки по Z80-плееру

## Вызов TR-DOS

Секторное чтение выполняется через стандартную точку входа `3D13h`:

```asm
LD D,track       ; логическая дорожка 0..159
LD E,sector      ; сектор 0..15
LD B,count       ; количество секторов
LD HL,destination
LD C,05h
CALL 3D13h
```

Плеер сам ведёт логические `track/sector`, поэтому не зависит от содержимого
каталожных переменных TR-DOS после запуска.

При всех записях в порт `7FFDh` плеер сохраняет бит 4 равным единице:

```text
17h  банк 7, экран A, 48K ROM
1Fh  банк 7, экран B, 48K ROM
```

Это обязательно для Beta Disk 128: выборка инструкции в области `3Dxxh`
подключает ROM TR-DOS только при выбранном 48K ROM. Значения `07h`/`0Fh`
оставляют выбранным 128K ROM, поэтому `CALL 3D13h` попадает не в диспетчер
TR-DOS.

## Карта памяти

```text
4000h–5AFFh  экран A, банк 5
5B00h–5FFFh  системная область и стек
6000h–621Ch  PLAYER.C и переменные
8000h–9FFFh  первый секторный буфер
A000h–BFFFh  второй секторный буфер
C000h–DAFFh  экран B при подключённом банке 7
```

Банк 7 остаётся подключённым к `C000h`; бит 3 порта `7FFDh` переключает видимый
экран. Поэтому декодер всегда может изменять скрытую фазу непосредственно.

В режиме `--no-flicker` вызов `swap_screen` заменяется тремя `NOP`, поэтому
бит 3 порта `7FFDh` остаётся нулевым и видимым всегда остаётся банк 5. Плеер
продолжает декодировать обе фазы и читать тот же поток, но показывает только
пространственно-дизерированную фазу A.

## Механическая дискета

На физическом дисководе чтение одного сектора за поле не гарантирует попадания
в следующий сектор текущего оборота. Для такой версии лучше отдельный драйвер
VG93/WD1793, читающий непрерывную группу секторов и обслуживающий переключение
экрана по счётчику времени либо через прерывания. Текущий образ является рабочим
потоковым профилем для эмулятора и быстрых дисковых эмуляторов.
