# Версия без финальных титров

19 сентября 2026 пользователь разрешил убрать финальные титры.
Основная история и дополнительная сцена после титров сохранены до EOF.
Это подготовленные данные новой версии; корневые TRD пока относятся
к проверенному выпуску `69754f3` с титрами.

## Монтаж и качество

- Удалён полуоткрытый интервал **[490,32; 580,32) с** исходника,
  то есть кадры **[4086; 4836)** при 25/3 кадра/с. Нумерация с нуля.
- 4971 → **4221 кадр**, 596,52 → **506,52 с** (8:26,52).
- 29826 → **25326 AY-тактов**: одновременно удалены `[24516;29016)`.
  Последний исходный кадр 4970 и последние шесть тактов сохранены.
- Склейка между чёрными кадрами. В оригинале история ещё продолжается
  около 489,8 с; сцена после титров появляется около 580,9 с. Эти части
  сохранены. Контактные листы проверены и по исходнику, и по ZX-кадрам.
- Вход — текущий age3 (`4b9e90d2…`). Все оставшиеся компактные экраны,
  атрибуты и 9-байтовые AY-состояния совпадают с ним побайтно. Дополнительной
  квантизации, изменения разрешения, частоты или обработки звука нет.
  Сохранена проверенная ранее точность age3 относительно исходного профиля;
  это не утверждение о побайтном совпадении age3 с исходным видео.

## Дельты и проверки

`prepare_edited_movie.py` создаёт совместимые входы `source/VIDEO_full.C.bin`,
`source/build_metadata.json` и `audio/50Hz/raw.bin` для `build_fast_sparse_trd.py`.
Дельты пересчитываются относительно оставшегося предыдущего кадра.
`repack_edited_fragments.py` также заново создаёт FSF1: на выходном кадре 4086
использует полные фрагменты, а атрибуты XOR считает от исходного кадра 4085.
Поэтому ссылки на удалённый кадр 4835 не остаются. Таблицы Huffman прежние;
скрипт умеет перестроить таблицу атрибутов, если на другом стыке возникнет
ранее отсутствовавший символ. Переписаны число кадров и границы групп.

Проверены все 4221 кадр независимым PC-декодером FSF1 и прежним декодером
видеопакетов, обратное восстановление промежуточного FHF1, каждый из 276
блоков ZX0 и все 25326 AY-тактов воспроизведением изменений регистров.
Четыре теста проверяют отсчёт границ, EOF, неверные интервалы и зависимости
видеодельт/FSF1 от удалённого предшественника.

На Z80 проверены **только 24 кадра 4072..4095** около склейки, двумя
раздельными CPU-стендами реконструкции и развёртки экранов. Код обоих
совпал с предыдущими измеренными версиями; изменение инструкций **0 T**.
Кадр склейки: **395018 T** суммарно; максимум выборки **453613 T** на
кадре 4091 против номинального бюджета 425448. Это не общий проигрыватель:
ZX0, метаданные, paging входа, IRQ/ULA, ROM и диск сюда не входят.
Новая гладкость воспроизведения не подтверждена, новые TRD не выпущены.

## Объём

| Данные | С титрами | Без титров |
|---|---:|---:|
| FSF1 перед ZX0 | 2 980 664 | 2 258 014 |
| Видео ZX0 + заголовки блоков | 2 005 434 | **1 474 256** |

Экономия видео — **531178 байт / 26,49%**. AY-команды существующего
формата `(регистр,значение)` занимают **118364 байта без сжатия**.
Итого **1592620 байт**: предварительный запас относительно трёх TRD
(1937664) — **345044**, относительно двух (1291776) — недостача **300844**.
Здесь AY измерен заново; прежняя оценка 77696 к этому расчёту не применяется.
Пока не учтены независимые старты частей, новый размер PLAYER, округление
секторов и интервалы interleave. Положительный запас — результат измерения
данных, а не доказательство готовности трёх воспроизводимых дискет.

## Воспроизведение опыта

Из каталога рабочего дерева; Python требует NumPy/Pillow и зависимости
прежних инструментов. Пути к исходному конверту и ZX0 можно заменить.

```powershell
python toolkit/prepare_edited_movie.py --states .tmp/spatial_predictors_cost/iteration_1.npz --ay ../audio-fidelity/toolkit/build_full_movie/audio/50Hz/raw.bin --output .tmp/no_credits --report toolkit/no_credits_timeline.json
python toolkit/repack_edited_fragments.py --fhs .tmp/spatial_predictors_cost/iteration_1.raw --motion-cache .tmp/spatial_predictors_cost/iteration_1.npz --selection .tmp/cache_aware_fragments/selection.npz --output .tmp/no_credits/fsf --report toolkit/no_credits_fragments.json
python toolkit/probe_zx0_storage.py --raw .tmp/no_credits/fsf/separated.raw --block-bytes 8192 --zx0 ../audio-fidelity/.tmp/bin/zx0.exe --cache .tmp/cache_aware_fragments/zx0 --output toolkit/no_credits_zx0.json --jobs 4
python toolkit/verify_edited_join.py --build .tmp/no_credits --timeline-report toolkit/no_credits_timeline.json --baseline-cpu toolkit/cache_aware_fragments_cpu.json --baseline-screen toolkit/compact_screen_cpu.json --output toolkit/no_credits_join_cpu.json
python toolkit/summarize_movie_edit.py --output toolkit/no_credits_summary.json
python -m unittest discover -s toolkit -p test_movie_edit.py -v
python toolkit/render_edited_preview.py --build .tmp/no_credits --ffmpeg ../audio-fidelity/.tmp/bin/ffmpeg.exe --output .tmp/no_credits/ending_preview.mp4 --first-frame 4050
```

Предпросмотр длится 20,52 с: показывает конец истории, склейку и всю
заключительную сцену. Синтез AY приближённый, частоты и шум продолжаются
через стык; PC-предпросмотр не служит тестом скорости Spectrum.
