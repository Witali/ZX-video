# Проверка вариантов хранения и вывода AY 50 Гц

## Решение

Допускается несколько дискет. Сохраняем исходные 6000 состояний AY: сглаживание
громкости уменьшает поток, но ухудшает атаки. Экспериментальные форматы пока не
имеют декодера Z80 и не включены в проигрыватель.

Все варианты сравниваются на тех же 1000 кадрах / 120 секундах.
Исходный AY SHA-256: `6353c9bd4fb73b1908a4a8a21a95c6e0d387f015c8debbf70e00787be7006776`.

## Хранение

| Вариант | Секторов VIDEO для единого тома |
|---|---:|
| Текущие пары регистр/значение | 2587 |
| Битовая маска изменённых регистров | 2580 |
| Команды с тегом регистра | 2570 |
| Ноты/громкости/шум отдельными событиями | 2566 |
| События, звук сгруппирован внутри блока | 2554 |
| То же, подбор границ блоков через DEFLATE | 2551 |
| XOR всех видеоданных + сгруппированные события | 2774 |
| XOR только разреженных видеоданных + события | 2680 |

Оценка вместимости — 2523 сектора при PLAYER 5120 байт. Новый декодер может
увеличить PLAYER, поэтому это только сравнение форматов. Разбиение на реальные
тома добавляет начальные состояния. DEFLATE используется для выбора границ,
конечные размеры измерены после ZX0. Варианты проверяют обратное преобразование.
Уплотнение строк по числу байтов также не улучшило результат: 2599 / 2569
секторов для пар / событий.

Медиана громкости на 3 тика уменьшает число записей AY с 10930 до 8253, но
F1 атак падает с 0.756014 до 0.736842; на 5 тиков — до 0.708333. Эти варианты
отклонены. Полные измерения и хеши сохранены в `experiments/ay_*.json`.

## Отклонённая развёртка RLE

Проверялась отдельная ветка для токена из 32 литералов. По таблице Z80:
полная строка 2447 → 1974 T (−473); другие токены получают проверку CP/JP,
+17 T каждый. Исходные формулы и измерения: `rle_full_rows_cycles.json`.
Измерение от входа команды до command_loop исключает IRQ, ULA, ROM и диск.

Во всём ролике только 4 таких строки и 7679 других токенов: суммарно
**+128651 T**, то есть замедление. В кадре 630 вывод 177793 → 184066 T
(+6273); в кадрах 623/624 выигрыш отсутствует. PLAYER вырос на 256 байт.
Fuse не показал улучшения максимального интервала: 128.549156 мс.
Изменение проигрывателя отменено; патч сохранён для воспроизведения эксперимента
в `experiments/rejected_full_row_unroll.patch`, профиль — рядом.

## Скрипты

- `benchmark_ay_encoding.py`: пары, маски, теги, события, группировка, XOR,
  подбор границ блоков и сравнение фактических размеров ZX0.
- `ay_events.py`, `test_ay_events.py`: обратимый экспериментальный формат событий.
- `benchmark_ay_smoothing.py`: сравнение сглаживания с неизменёнными нотами.
- `benchmark_rle_full_rows.py`: сравнение двоичных PLAYER до/после развёртки.
- `profile_sparse_packets.py`: состав реальных пакетов и стоимость вывода.
- `summarize_ay_delivery.py`: интервалы видео и задержки подготовки из Fuse.

Параметры воспроизведения доступны через `--help`; входные данные соответствуют
`AY_INTERRUPT_RESULTS_ru.md`. Кеш ZX0 проверяет результат распаковки при каждом
повторном использовании. Изменения хостовых инструментов не меняют Z80:
стоимость прежних команд и прерывания остаётся прежней (дельта 0 T).
