# Вывод масок, точек, серий и RLE через регистры

15 сентября 2026. База — `251a79c`. Все 1000 кадров и AY сохранены на одной
TRD; 112 сжатых блоков побайтно прежние, 2517 секторов данных. PLAYER уменьшился
с 4352 до 4096 байт: свободно пять секторов вместо четырёх.

## Изменение

Указатель потока переносится из IX в HL один раз на команду. BC адресует
таблицу дизеринга, DE — верхнюю экранную строку; нижняя отличается на 0100h.
AF′ хранит маску или счётчик, HL′ по-прежнему принадлежит часам прерываний.
Для повторов RLE цвет преобразуется один раз на серию, затем два готовых
байта записываются в строки. Формат команд и степень сжатия не меняются.

## Такты Z80

[Zilog UM0080](https://www.zilog.com/docs/z80/um0080.pdf), вход команды →
`JP command_loop`, без диспетчера, IRQ, contention и ROM. N — число значений,
R в spans — число серий; L/R в RLE — число literal/repeat токенов, NL/NR —
соответствующее число выходных значений, NL+NR=32.

| Команда | До, T | После, T | Разность, T |
|---|---:|---:|---:|
| Маска | 1287+68N | 984+60N | −303−8N |
| Точки, N>0 | 220+189N | 207+114N | −13−75N |
| Пустые точки | 220 | 217 | −3 |
| Spans | 220+178R+126N | 243+122R+90N | 23−56R−36N |
| RLE | 208+95L+152R+183NL+167NR | 189+50L+147R+90NL+47NR | −19−45L−5R−93NL−120NR |

Подготовка адреса и регистров — 153 T. Чтение компактного значения с выводом
двух байтов — 57 T: `LD C,(HL)` 7, `INC HL` 6, два `LD A,(BC)` по 7,
два `LD (DE),A` по 7, четыре INC/DEC регистра по 4. Цикл повторов RLE:
два `LD A,H/L` по 4, два `LD (DE),A` по 7, три INC/DEC по 4 и DJNZ 13/8:
47 T, последняя итерация 42 T. Завершение команды — 35 T.
Пустая команда spans стала на 23 T дороже; кодировщик её не выпускает.
Короткий ISR неизменен: 61 → 61 T, разность 0.

Для строки из одного цвета RLE: 5704 → 1840 T (−3864); для literal-строки:
6159 → 3119 T (−3040). [Машинные суммы](stream_drawing_cycles.json) получены
исполнением бинарников предыдущего и нового плеера. Старый счёт spans
в метаданных включал диспетчер; здесь обе стороны имеют одинаковые границы.

## Полный прогон

Fuse 1.9.0, Spectrum 128 + Beta128, 3 546 900 Гц; 999 интервалов показа.

| Показатель | База | Новый вывод |
|---|---:|---:|
| Средняя скорость, кадр/с | 8,235 | 8,246 |
| Средний интервал, мс | 121,440 | 121,271 |
| Максимальный интервал, мс | 457,540 | 363,308 |
| Интервалов длиннее 125 мс | 274 | 238 |
| CPU подготовки, среднее T | 237 303,941 | 211 101,761 |
| CPU подготовки, максимум T | 837 711 | 605 829 |
| Старт PLAYER → первый кадр, мс | 3545,200 | 3556,666 |

Средний CPU сократился на 11,04%, пиковый на 27,68%. В CPU-счёт не входят
ROM, диск, прерывания, contention и ожидание; полное время учитывает Fuse.
30 тестов прошли, включая все 96 строк, оба экрана, границы страниц,
все 256 значений дизеринга в RLE, короткие/длинные и смешанные серии.
Полный CPU-валидатор сверил каждый экран и AY; Fuse завершил все кадры без
fatal и недогрузки. Пиксели внутри Fuse отдельно не сверяются. Физический
дисковод не измерялся. Номинальный темп потока остаётся 25/3 кадра/с.

**Плавные 8 кадров/с ещё не достигнуты.** Помимо тяжёлых кадров, в трассе
есть шесть чтений около 193 мс; каждое следует за поддержанием мотора
чтением в 7C00h. Этот сектор позже повторно читается в кольцо. Измеритель
теперь записывает адрес назначения каждого чтения для проверки этой причины.
Следующие шаги: устранить повторное ожидание сектора и распределить перенос
сжатого блока/распаковку между кадрами.

## Воспроизведение

Параметры сборки совпадают с [cached seek](CACHED_SEEK_RESULTS_ru.md).
Выходной каталог: `build_stream_rle_v9`.

```text
python build_fast_sparse_trd.py --source-build SOURCE --output build_stream_rle_v9 --packing zx0 --zx0 /path/to/zx0 --drawing registers --disk-reader trdos503-irq --disk-layout interleaved --pacing deadline --zx0-decoding incremental --motor-keepalive-fields 64 --prefetch-quota 3 --rom-clock full --disk-seek cached
python -m unittest test_fast_drawing test_fast_seek test_playback_schedule test_disk_layout test_blocked_stream test_packed_stream test_incremental_zx0
python benchmark_stream_drawing.py --baseline-build build_cached_seek_v9 --build build_stream_rle_v9 --output build_stream_rle_v9/cycles.json
python measure_fuse.py /path/to/fuse.exe build_stream_rle_v9 --output build_stream_rle_v9/fuse_timing.json
python validate_fast_sparse.py build_stream_rle_v9 --source-build SOURCE --fuse-timing build_stream_rle_v9/fuse_timing.json --output build_stream_rle_v9/cpu_validation.json
```
